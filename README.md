Portfolio cá nhân của **Y Nam Knul (NamK)**, Marketing Director tại KAZA Restaurant và Bích Vân Store.

- Trang đang chạy: https://kthegoat.vercel.app
- Trang tĩnh, một file `index.html` (GSAP, Lenis, three.js qua CDN). Push lên `main` là Vercel tự deploy.
- Toàn bộ bối cảnh, quyết định thiết kế và việc còn dang dở nằm trong [`CLAUDE.md`](CLAUDE.md).
